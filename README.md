# InkPlatform — сервер

Node.js 18+ · Express · SQLite (better-sqlite3). Один процесс, один файл БД.

## Запуск
```bash
cd inkplatform-server
npm install
export JWT_SECRET="длинная-случайная-строка-32+символа"   # openssl rand -hex 32
export ADMIN_NICKS="твойНик"                               # необязательно, см. ниже
node server.js
```
Сайт: `http://localhost:3000` (положи свой `inkplatform.html` как `public/index.html`).
Админ-панель: `http://localhost:3000/admin`.
Переменные: `PORT`, `DB_FILE`, `JWT_SECRET` (обязательна), `ADMIN_NICKS`, `DATABASE_URL` (PostgreSQL: сюда сохраняется снимок базы и скриншоты, чтобы данные не пропадали на Render).

## Как добавлять админов и модераторов
Роли: `user` < `moderator` < `admin`.

| Роль | Может |
|---|---|
| moderator | проверять и подтверждать результаты, банить/разбанивать игроков с ролью ниже, отменять матчи и ставить победителя, смотреть журнал |
| admin | всё то же + назначать роли, выдавать/забирать Ink Points и Elo, управлять админами |

**Первого админа создай одним из двух способов:**
1. **Консоль (надёжнее всего).** Зарегистрируйся на сайте обычным игроком, затем на сервере:
   `node server.js set-role ТвойНик admin`
2. **Переменная `ADMIN_NICKS`.** Ник из списка (через запятую) становится админом при регистрации.
   Зарегистрируй этот аккаунт сразу после запуска, пока ник не занял кто-то другой, затем можно убрать переменную.

**Остальных назначай из панели:** `/admin` → «Игроки» → выпадающий список роли (виден только админам).
Вернуть игрока в обычные: `node server.js set-role Ник user` или та же панель.
Последнего админа убрать нельзя. Каждое действие модерации пишется во вкладку «Журнал».

## Как работает проверка результатов
1. Подбор: 10 игроков одной лиги (PC/Phone) → матч с номером `000001`, `000002`… (автоинкремент), команды A/B по Elo.
2. Игрок отправляет скриншот + победителя + K/D/A. Принимается только от участника матча, один раз, png/jpg/webp до 5 МБ.
3. `Result Pending`. Если обе команды прислали одного победителя — матч подтверждается автоматически (±25 Elo, +50/+20 IP).
   Если мнения расходятся — матч уходит в «спорные», решает модератор во вкладке «Результаты».
4. Скриншоты лежат в `uploads/` и отдаются только модераторам через `/api/admin/shot/:file`.

## API (кратко)
`POST /api/auth/register|login` · `GET /api/me` · `GET /api/leaderboard` · `GET /api/stats`
`POST /api/queue/join {league}` · `GET /api/queue/status` · `POST /api/queue/leave`
`GET /api/matches/mine` · `GET /api/matches/:id` · `POST /api/matches/:id/result` (multipart: screenshot, winner, k, d, a)
`GET /api/friends` · `GET /api/friends/search?q=` · `POST /api/friends/request|accept` · `DELETE /api/friends/:nick`
`GET /api/missions` · `POST /api/missions/:key/claim` · `GET /api/shop` · `POST /api/shop/buy|equip`
`/api/admin/*` — только moderator/admin.

## Важно перед запуском в интернет
- Ставь за HTTPS-прокси (Caddy/nginx); токены передаются в заголовке.
- Лиги PC/Phone проверяются на сервере по User-Agent. Это лучше, чем проверка в браузере, но подделывается; полностью это не решить без привязки аккаунта к устройству.
- Платные рамки (₽) возвращают 402: платёжный провайдер не подключён.
- Античита и проверки самих скриншотов нет — это работа модераторов.
- Делай резервные копии `ink.db` и папки `uploads/`.
- Сайт (`public/index.html`) работает через этот сервер: вход, подбор, результаты, друзья, миссии, магазин. Открывать его нужно с адреса сервера, а не как файл.

## Если на телефоне (Termux) не регистрируется
- Открывай сайт по адресу, где запущен `node server.js` (например `http://localhost:3000`), а не через другой веб-сервер.
- `better-sqlite3` собирается из исходников: нужны `pkg install nodejs python make clang`. Если сборка не прошла, сервер не запустится.
- Проверка: открой `/api/health`, должно быть `{"ok":true}`. Ошибки сервера пишутся в терминал, где он запущен.

## Если сайт медленный в Termux
- Держи проект в домашней папке Termux (`cd ~`), а не в `/sdcard` или `storage/shared`: на общем хранилище SQLite очень медленная.
- Сервер пишет в терминал строки `МЕДЛЕННО ...`, если запрос идёт дольше 300 мс. Пришли их, если тормоза останутся.

## Termux: сайт «зависает» через некоторое время
Android усыпляет Termux, когда ты переключаешься в браузер, и сервер перестаёт отвечать. Что делать:
1. Запускай через `sh start.sh` (включает `termux-wake-lock`) или нажми «Acquire wakelock» в уведомлении Termux.
2. Настройки Android → Приложения → Termux → Батарея → «Без ограничений».
3. Секрет подписи теперь создаётся автоматически (файл `.jwt_secret`), `export JWT_SECRET=...` больше не нужен, а входы не слетают после перезапуска.

## Новое: калибровка, режимы, подбор, репорты, расширенная модерация
- **Калибровка.** Новый игрок стартует со скрытым Elo 100. Elo и место в рейтинге видны только после 10 матчей (до этого «Калибровка n/10»). В калибровке победа даёт +50 к скрытому Elo, поражение 0; дальше ±25.
- **Режимы 1×1, 2×2, 5×5** в обеих лигах. У каждой лиги и режима своя очередь (PC и Phone не пересекаются).
- **Подбор по Elo.** Диапазон ±200, каждые 10 секунд ожидания расширяется на +100. Игрок видит текущий диапазон.
- **Репорты:** читы, багоюз, игра не в своей лиге, токсичность, руин игры. Лимит 5 в сутки. Админ-панель → «Репорты».
- **Бан:** игрок видит «Вы забанены до … по причине: …» (или «навсегда»). Банят модераторы и админы, разбанивают тоже они.
- **Только админ:** снять/сбросить калибровку (себе и другим), накрутить матчи с нужным K/D/A, удалить матч (Elo и статистика откатываются), удалить аккаунт.
